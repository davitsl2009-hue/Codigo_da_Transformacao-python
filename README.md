# 📝 README - Sistema de Login com Autorização de Idade

## 📌 Descrição
Este projeto é um programa simples em **Python** que simula um sistema de login para um site de apostas.  
Ele verifica a idade do usuário e, caso seja maior de 18 anos, solicita login e senha para liberar o acesso.  
Se o usuário for menor de idade ou inserir a senha incorreta, o acesso é negado.

---

## 🚀 Funcionalidades
- Solicita a idade do usuário.
- Verifica se o usuário é maior de idade (>= 18 anos).
- Solicita login e senha apenas para maiores de idade.
- Valida a senha (senha correta: `vocacao2025`).
- Exibe mensagens de autorização ou bloqueio de acesso.

---

## 📂 Estrutura do Código
1. Exibe título do sistema.
2. Solicita a idade do usuário.
3. Condicional:
   - Se idade >= 18:
     - Solicita login e senha.
     - Verifica se a senha está correta.
   - Caso contrário:
     - Bloqueia o acesso.
4. Exibe mensagens de acordo com cada situação.
